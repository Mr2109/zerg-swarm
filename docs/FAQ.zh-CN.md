## 部署与启动

**Q：主控启动就退出，提示"未配置共享令牌"？**
这是有意的防呆。空令牌会让所有 `/api/*` 返回 401，而进程看起来一切正常——最难排查的一类故障。
按提示设 `ZERG_AUTH_TOKEN`，或写入 `~/.zerg/token`（单行）。

**Q：所有 API 都返回 401？**
令牌没送到。检查：① 该进程的环境里有 `ZERG_AUTH_TOKEN` 吗（`set -a; . ./.env; set +a` 之后再启动）；
② 客户端发的是 `X-Auth-Token` 头吗；③ 网关还接受 `Authorization: Bearer` 与 `x-api-key`（会被转成 `X-Auth-Token` 透传）。

**Q：UI 显示"主控离线"？**
先 `curl` 主控端口：能 401 就说明服务在跑、是令牌问题；连不上则看 `ZERG_API_BASE` 与防火墙。
（UI 内部对回环请求禁用了系统代理——如果你自己写客户端，注意某些代理设置会吞掉 `127.0.0.1` 请求。）

**Q：子端在线，但加载模型失败？**
看子端日志与后端的真实报错：权重路径、显存不足、后端二进制不在 `PATH`、端口被占。
`mem_gb` 填得比实际小会让调度过度乐观——宁大勿小。

**Q：能不能不装 `rtk`？**
能。未安装时自动降级（不再给命令加前缀）；也可 `ZERG_RTK=0` 显式关闭。

**Q：`web_search` 报错？**
它依赖自建 searxng（AGPL 组件，**不随仓库分发**）。用 `scripts/install-searxng.sh` 装好后，
用 `ZERG_SEARXNG_PY`/`ZERG_SEARXNG_SETTINGS` 指向它；不装则联网搜索工具不可用，其余功能不受影响。

## 使用

**Q：模型名可以自己起吗？**
可以。名字只是键——在 `agent_models.yaml`（子端怎么拉起）与 `gateway/fleet.yaml`（主控有哪些候选）里登记一致的键即可。
适配器按**前缀**匹配，例如 `example-35b` 系列共享同一套启动参数。

**Q：可以同时跑两个模型吗？**
单机上不行（**单槽**约束：显存现实）。把第二个模型放到另一台机器、作为同一模型的候选或另一个模型，即可并行。

**Q：任务执行会不会删我的文件？**
shell 的删除类命令受**范围闸门**约束：只允许作用于任务工作区 `ZERG_EXTRA_ALLOW_DIR` 白名单目录；
家目录、根目录及其祖先一律拒绝并给出可执行的替代指引。**不要**把白名单指到敏感目录。

**Q：任务卡住/不停重发同样的命令？**
先看 CA 事件日志 `events.jsonl`（默认 `/tmp/zerg-ca-logs/<时间戳>/`，也可 `ZERG_CA_LOG_DIR` 改）：
重复的工具调用 + 递增的轮次通常意味着"系统没给出可执行反馈"（路径被拒、参数格式错）。
把日志里的拒绝信息喂给维护者，或检查任务描述里写的路径是否在白名单内。

**Q：内部任务引擎是什么？要开吗？**
不要开。它包含自我巡检/清理类任务（会删文件），默认关闭（`ZERG_INTERNAL_TASKS` 未设置即关闭）。
本项目的立场是：这类自动清理必须由使用者在明确了解后果后自行开启。

## 数据与隐私

**Q：虫族会回传数据吗？**
不会。全部组件跑在你自己的机器上，没有遥测、没有账号体系。模型调用也只发往你自己配置的后端。

**Q：对话/记忆存在哪？**
对话库 `~/.zerg-chat/chat.db`；记忆 `~/.zerg/memory/`；工具状态 `~/.zerg/state/`。
都可以用环境变量搬到别处（见 [CONFIGURATION.zh-CN.md](CONFIGURATION.zh-CN.md)）。

**Q：怎么备份？**
备份上面三个目录即可（SQLite 建议用 `VACUUM INTO` 而不是直接拷 .db 文件）。

**Q：令牌/密码在仓库里有吗？**
没有。仓库内**零明文凭据**：令牌走环境变量或 `~/.zerg/token`；
发布流水线还会在导出前扫描明文凭据、私有路径与内网地址，命中即中止。

## 开发

**Q：我该从哪读代码？**
`core/internal/api`（调度与 HTTP）→ `core/internal/chat`（对话与工具循环）→ `core/internal/agent`（工具与闸门）
→ `agent/`（子端）。桌面 UI 在 `ui/src`。

**Q：怎么加一个工具？**
实现 + 注册到工具注册表 + 写 `tools/<name>.md` 履历（并同步工具简介——它同时供给 UI 与模型提示）。
注意目录里有两份"清单"（常驻 L0 与延迟加载），注册表是单一真相源，有单测保证两边一致。

**Q：怎么看一个机制是不是真的在跑？**
不要只读代码。本项目大量使用"进程 + 数据双证"：例如查某个计数器是否落盘、某个端点是否真的注册、
某个 flag 是否真的被读取。这一条在贡献指南里也是硬要求。

## 命令面

**Q：资源接口里的信任级别变成机器码了，我的脚本怎么办？**
数据面里它是 **ASCII 机器码**，闭集三个：`new`（新入库／用满 100 次前）、`official`（正式）、`unknown`（未注册／缺值）。
接口响应（`zerg resource ls` 投影的那一份）与状态文件（`~/.zerg/state/zerg-resources.json`）里发出去的都是机器码；
中文只住在界面显示层（界面语言包里的键），界面上照旧显示中文。
**旧中文字面量的调用方须同步**：旧取值是 `新`／`正式`／`未知`，拿它们做比较的脚本、客户端、适配器一律要改成比机器码。
旧状态文件里存的中文只在校验/读入时翻译一次（`新`→`new` · `正式`→`official` · `未知`/空串→`unknown`），写侧只写机器码，旧件不删不改。
取值是**破坏性接口变更**的一部分（服务端与界面制品两侧同批改）⇒ 只改一侧就会互相对不上。

**Q：往归档区里写文件被拒，说是只读？**
归档区不是普通目录，它是**只读镜像按需装载**的那一态 —— 写面被拒是它的本来面貌，不是权限位没设对（`chmod` 也改不动只读卷）。
装载面只有一个脚本、三个动作（各自幂等 · 不常驻 · 不装开机自启）：
`bash scripts/svc/archive-mount.sh status`（报挂载态）· `bash scripts/svc/archive-mount.sh off`（摘下）· `bash scripts/svc/archive-mount.sh on`（挂上）。
要改归档内容：先 `off` 摘掉只读镜像，改完再 `on` 挂回。
★ 未挂那一态**不是**"正常"：`status` 报"未挂"时**退码 1**，而且此刻原路径是**悬空符号链接**——读它会**明确失败**（不是"读到空内容"）；别把未挂态下的原路径当普通目录写。
退码：`0` 成功 · `1` 失败（含 `status` 报"未挂"）· `2` 不给结论（前提不可判：镜像件不在／原路径不是符号链接／两处读数打架）· `64` 用法错。
摘不下（有进程正占着镜像里的件）时先看谁占着，**不要**换 `-force` 硬摘。

**Q：我只想提交自己点名的件；门禁红了还想要带账放行？**
点名单路径：`zerg repo commit --only <路径> --message <题>` —— 它**不** `git add`（点名的路径直接交给 `git commit --only`），索引面**允许非空**（别人的暂存一件不动）。
多件要**逐件**写 `--only`（一次只吃一枚值）；`.`／`-A`／通配／`:` 一律拒（那是批量暂存的后门）。
三态：`--dry-run` 出计划件（零副作用 —— 未暂存、未提交、未跑门禁）· 缺 `--yes` ⇒ **不执行**（退码 2 · 从不提问）· 两态齐 ⇒ 真跑。
真跑**先过快速档**（`bash scripts/gates/precommit-gates.sh --fast --outdir <目录>`）：rc 不是 0 就**不提交**，索引面与工作树逐字未动。
确需人签例外时用已拍的带审计旗标：`--waive <步名> --reason <一句>` —— 缺 `--reason` 直接拒执（退码 2：没写理由的豁免不给）；
步名必须**真出现在这一趟的报面上**，否则例外不生效；每次例外落审计（谁 · 什么时候 · 哪一步 · 什么理由），事后可回读。
命令面**不提供** `--no-verify`（绕行只许人显式做）。
