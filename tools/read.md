# 工具履历：read

> 版本：v1.0.2 ｜ 类别：CA ｜ 更新：2026-09-09

## 说明

读取文件内容（v1.0.2——多文件类型可读：文本/PDF/Office/epub 自动抽取；GBK/UTF-16 自动转码；二进制/图像/音频/视频委托专用工具；行号默认开）。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| path | — | 文件路径(相对 WorkDir) |
| offset/limit | 1/500 | 分页 |
| num | true | 行号(1-based,格式 `N │ 行`) |
| format | auto | auto=类型探测;raw=强制原文文本 |
