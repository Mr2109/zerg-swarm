# 工具履历：ls

> 版本：v1.0.2 ｜ 类别：CA ｜ 更新：2026-09-08

## 说明

列出目录内容（目录结构概览——v1.0.2: 目录恒前/点项默认隐藏/60 行截断+省略引导/摘要行）。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| path | "." | 目录路径 |
| limit | 60 | 最大列出行(0=不截断) |
| dir_only | false | 只列目录 |
| hidden | false | 显示点文件/目录 |
| pattern | "" | 名称 fnmatch 过滤(与 glob 分工) |
| sort_by | name | name/time/size(目录恒前;time 附 MM-DD HH:mm 列) |
