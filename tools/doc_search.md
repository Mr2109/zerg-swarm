# doc_search —— 项目文档检索

**版本**：v1.0.0（2026-09-03——v2.5.8 文档体系 t5）
**入口**：core/internal/chat/chat_tool_docsearch.go（L0 常驻工具——对话/CA 均可用）

## 作用
关键词 → docs（项目文档全版本 + 常青）命中文件+片段——替代全文读——片段入上下文（模型查文档先 doc_search——不 open 全文）。

## 用法
- query（必填）：关键词（空格分词——AND 匹配）
- scope（可选）：限定范围子串（如 `v2.5.8`/`常青`）——默认全 docs

## 行为
- 扫描 docs/项目文档/v* + docs/常青（.md）——大小写不敏感
- 命中排序：**当前版（★）→ 常青 → 历史版（⏳）**——当前真相优先
- 每文件最多 2 个命中行片段（150 字截断）——总输出限 6 文件 / 3500 字（超长提示缩小 scope）
- 无命中：提示换词/scope（不是空结果——引导防循环）
