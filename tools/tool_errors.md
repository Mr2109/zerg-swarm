# 工具履历：tool_errors

> 版本：v1.0.0 ｜ 类别：CA/对话 ｜ 更新：2026-09-02

## 说明

工具错误统计（聚合桶——跨对话持久）——为工具优化下个版本准备真实错误数据。

背景：渐进式常驻设计第四章（Mr2109 2026-09-02）——工具资产化闭环缺"错误反馈驱动下版"。

## 用法

- `tool_errors`（无参）→ 全局错误 Top 20（按 count 降序）
- `tool_errors {"tool":"port_check"}` → 该工具错误明细（param/exec 分类——参数样本）

## 输出解读

- `[param]` = 模型传参错（调用方锅——但说明描述/schema 不清——工具该优化）
- `[exec]` = 工具/服务真错（服务挂/依赖坏——该修）

## 数据

- 存储：/tmp/zerg-tool-errors.json（聚合桶——同工具+同错误消息=一条+count）
- 上限：100 桶/工具/类（超了丢最老）——90 天老化
- 消融：处理完后清除（人工或后期虫族自动任务——工具升级后自动消融）
