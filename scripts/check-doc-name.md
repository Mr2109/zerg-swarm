## 七条判据（规则号 ↔ 《清单》§1 七类）

| 规则 | 档 | 判据 | 出处 |
|---|---|---|---|
| **N1** | FAIL | ①大小写：文件词干全为大写拉丁字母（≥3） | §1 ①（与 mkdocs `index.md` 约定冲突；本卷 APFS 大小写不敏感） |
| **N2** | FAIL | ②空格/全角：名称含 `U+0020` / `U+3000` / 全角标点 | §1 ② |
| **N3** | FAIL | ③日期后缀：词干含 `-YYYYMMDD` 或 `-YYYYMM` | §5 ③（日期移入 frontmatter `updated_at`）+ §5 ⑦（6 位日期） |
| **N4** | FAIL | ③版本段不在尾位：`-vX.Y` 其后还有分隔段 | §5 ③（`名-…-vX.Y[-YYYYMMDD]`） |
| **N5** | WARN | ④前缀序号不一致：同层 `NN-` 与无前缀并存（各 ≥ 2） | §5 ④（结构级 · 只登记不改 · 牵动 nav/白名单） |
| **N6** | FAIL | ⑥同目录同基名、扩展名不同（去**最后一个**扩展名后相同，且至少一方是文档/脚本面扩展） | §1 ⑥（K8 那类）+ §4.3 允许对 |
| **N7** | WARN | ⑤中英紧邻：同一分隔段内汉字与拉丁字母直接相邻 | §5 ⑤（「机械插 `-` **需人审**」） |

**两条档位口径（写死在脚本里，不是感觉）**

- **目录名命中一律 WARN**：改**目录名**是结构级动作（牵动 nav / 白名单 / 引用），《清单》§5 ④ 明写「只登记不改」；
  **文件名**命中才算 FAIL。⇒ 同一条判据，落在目录上只告警。
- **冻结区不计入退码**：`docs/项目文档/`（17 套快照 §8.1）· `docs/issues/`（引擎数据 §1.3）按《清单》§2「高（冻结·不改）」**只登记不改**
  ⇒ **命中数照报**（含逐条例），但不进 rc；要进退码用 `--count-frozen`。

## 用法

```bash
cd "<repo>"

python3 scripts/check-doc-name.py                      # 全仓扫描域（排除名单同《清单》§0）
python3 scripts/check-doc-name.py --target docs --max-examples 40
python3 scripts/check-doc-name.py --json               # 机读：live/frozen 分桶 + 逐规则命中 + 豁免命中
python3 scripts/check-doc-name.py --list-rules         # 七条判据 + 出处 + 档位口径
python3 scripts/check-doc-name.py --list-exempt        # 例外表三档全列（含条数自证）
python3 scripts/check-doc-name.py --self-test          # 成对负控（16 条用例，真命令行 + 真退出码）
python3 scripts/check-doc-name.py --no-self-test ...   # 内部子进程用（防递归）
```

**退码三档**（优先级 **2 > 1 > 0**）：`0` 全绿（告警不阻断）· `1` 有不合规项（**只报告不改**）·
`2` 不给结论（用法错 / 目标缺件 / 扫描域为空 / **例外表条数不符** / 自检未过）。自检不过 ⇒ 拒绝扫真目标。
