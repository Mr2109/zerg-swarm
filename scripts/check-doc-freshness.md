## 2. 四条门禁：入参 · 判定 · 退码

### D1 · 引用路径存在
- **入参**：语料清单（`corpus`）· 解析基准集（`base_roots` = 仓根 + `core/agent/wall/ui/gateway/mcp/shared/docs/scripts/tools/publish`）· 引用域开关（`external_domain_paths`）· 归一化白名单。
- **判定**：抽 `[..](target)` 与 `![..](target)`；`scheme://`/`mailto:`/`//` 分流外链；纯 `#x` 归 D3；相对路径在 `{引用文件目录, 仓根, 各模块根}` **任一命中即过**；目录目标也算命中；先 `unquote` 再判；**用「树上真实路径字符串集合」比对，不用 `os.path.exists`**（APFS 大小写不敏感会让 `README.MD` 判绿而 Linux CI 判红 ⇒ 这类记**黄**）。
- **退码**：`0` 全可解析 · `1` 有断链 · **`2` 语料为空 或 该 scope 里 0 条相对引用（空转 ⇒ 不给结论）**。

### D2 · 引用 `文件:行` 有效
- **入参**：归一化白名单（噪声类别**必须计数**）· 解析基准集 · 行号语义（`f:12` / `f:10-20` / `f:1,3-5`，取**最大行号**）· 裸文件名策略。
- **判定**：
  - **R1（含 `/` 的路径）**：基准集里存在 **且** 最大行号 ≤ 文件总行数；
  - **R1 的假红对冲**：基准集没命中时做**唯一后缀匹配**（`api/handlers.go` → `core/internal/api/handlers.go`）；**唯一命中 ⇒ 过**，多份 ⇒ 黄（歧义），0 份 ⇒ 红。**这条不做，首跑就 3 成假红**（调研稿实测 R1 缺失率 34.27%）；本机实测：main 档靠后缀匹配**救回 64 条**（`过·后缀唯一命中 = 64`）。
  - **R2（裸文件名）**：同名池（**去镜像、去冻结归档**）里**恰好 1 个 ⇒ 过**、**0 个 ⇒ 红**、**>1 ⇒ 黄（歧义，只入清单）**。
  - **噪声类别**：`IP:端口` / 省略号路径 / 占位符 / 命令行样式（含空格或 `=`）/ 尾部斜杠 / 绝对路径 / URL / 无扩展名 / 非法行号 —— **一律计数**（否则可以用噪声把引用洗白）。
  - **URL 先掩码再抽**（否则 `host.com:80` 被当裸文件名 ⇒ 假红；本机 main 掩掉 **4368** 段 URL）。
- **退码**：`0` 无红 · `1` 有红 · **`2` 基准集配置缺失 或 0 条引用（空转）**。

### D3 · 断链断锚
- **入参**：slug 规范（冻结 · profile + `spec_doc`）· 带锚链接范围 · 是否纳入 wiki 链接（默认**不纳入、单列计数**）· 同文件重复 slug 编号规则。
- **判定**：链接带 `#anchor` 且目标解析为 `.md` ⇒ 按冻结规则算目标文件**全部标题 slug**（含显式锚 `{: #slug }` / `{#slug}` 优先）⇒ 命中即过；同文件重复 slug 追加 `-1/-2`；空 slug 兜底 `s<序号>`。大小写差 ⇒ **黄**（同 D1 的理由）。目标文件本身不存在 ⇒ 归 D1，这里只单列（不重复报）。
- **退码**：`0` 无断 · `1` 有断锚 · **`2` slug 规范未落盘 / `spec_doc` 不存在 / 0 条带锚链接（空转）**。

### D4 · 生成式参考 drift
- **入参**：生成器清单（`d4.generators`：源 → 产物 → 重建命令 → 修法）· 干净临时目录 · （本实现不需要 git 写）。
- **判定**：在 `$TMPDIR` **重建**（**绝不就地生成**）→ 与仓内提交物**逐字节**比对：
  - 一致 ⇒ 过；
  - **归一化后一致**（去尾空格 + 时间戳/版本号/本机路径 → `<VAR>`）⇒ **黄**（只有易变行不同）；
  - 否则 ⇒ **红**，报错**必带「跑哪条命令修」**（K8s 形态）；
  - 目标在冻结归档/镜像 ⇒ 只登记不判（除非 `--strict-all`）。
- **退码**：`0` 全对 · `1` 有 drift · **`2` 缺生成器 / 产物不存在 / 0 个可比对（不给结论）**。
- **登记的两个生成器**：`tools/doc_index_gen.py`（→ `docs/项目文档/*/INDEX.md`，17 个目标）· `tools/gen_tools_md.py`（→ `publish/docs/TOOLS.zh-CN.md`，源 `core/internal/chat/chat_tool_registry.go`）。
- **与 spec 的一处实现偏离（已声明）**：spec 写「`git status --porcelain` / `git diff --exit-code`」；本实现改为「临时目录重建 + 与提交物字节比对」——**判据等价且不需要 git 写权限**（本路明禁改仓），也避免把重建产物倒进工作树。

## 4. 归一化白名单 / 排除名单 / 引用域 / 夹具 / 拒绝域

### 4.1 归一化白名单（**不算引用，但一律计数** —— 计数在结果表里可核）
| 类别 | 处置 |
|---|---|
| 外链（`scheme://` · `mailto:` · `//`） | 不判（上游：外链 can time-out a lot） |
| 页内锚（纯 `#x`） | D1 只计数，判定归 D3 |
| 绝对路径样式（`/` · `~` 开头） | 单列不判（站点根语义歧义） |
| 代码块内链接（``` 围栏内） | 单列不判（语法示例） |
| 占位符目标（含 `< > { } * $`） | 单列不判 |
| **省略号目标**（含 `…` / `...`） | 单列不判 |
| **语法示例目标**（无 `/`、无 `.`、≤24 字，如 `[name](url)`） | 单列不判 |
| 空目标（`[](#)`） | 单列不判 |
| wiki 链接 `[[…]]` | 单列不判（实测全是语法示例） |
| 大小写不符 | **黄**（APFS 判绿、Linux CI 判红） |
| D2 噪声九类 | 只计数不判（URL 先掩码） |
| D4 易变行 | 归一化后一致 ⇒ 黄 |

### 4.2 白名单的效果（**本机实测，可复跑**）
| scope | 有白名单（断链） | `--no-whitelist`（断链） | 白名单消掉的假红 |
|---|---|---|---|
| `wide` | 15（本地 7） | **28**（本地 17） | **13 条（46%）** |

## 6. slug 冻结规范：实现与回测（§5.6① 八条）

**实现**：NFC（不做 NFKD / 不做 ASCII 折叠）→ `lower()`（非 `casefold`）→ 只保留 `\p{L}\p{M}\p{N}` + `_` + `-`（其余一律删）→ **空白逐字符 → `-`**（`a  b` → `a--b`）→ 空结果兜底 `s<序号>` → 同文件重复追加 `-1/-2` → 引用一律 `path#slug`。

**回测（真仓现跑，决定性证据）**：
- 用仓内**现存手工锚链**回测：`wide` **21/21 解析**（断 0）· `mirror` **42/42 解析**（断 0）⇒ 与 §5.6①「A GitHub 42/42 通过」一致；换 VitePress/mkdocs 默认规则会 0/42。
- **空 slug：0 个**（`wide` 9,677 个标题 / `mirror` 23,171 个标题里都没有空 slug）—— 兜底分支存在但今天量不到。
- **已知规范歧义（如实报）**：§5.6③ 把 U+3000 列进「一律删除」，§5.6④ 又说「空白 → `-`」。默认取 **`github`** 档（含 U+3000 → `-`，与 GitHub 逐字一致）；`--slug-profile docv1.2` 走字面读法。**实测：语料里含 U+3000 的标题 0 个 ⇒ 两档零差异**（分歧在本仓量不到，但按 github 档走，与 42/42 的回测口径一致）。
